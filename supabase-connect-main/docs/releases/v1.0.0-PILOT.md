# Kanisa Connect v1.0.0 Pilot Edition

## Overview

Version 1.0.0 Pilot Edition is the first real-parish pilot release of Kanisa Connect. It focuses on stable parish operations, role-based workspaces, Catholic content, giving workflows, pastoral workflows, and operational readiness.

## Highlights

- Unified Workspace Framework for member, pastoral, church admin, finance, and super admin experiences.
- Role-oriented dashboards with assistant briefings, priorities, snapshots, timelines, and quick actions.
- Bible reader and whitespace-tolerant Bible search.
- Daily readings, saints, liturgical calendar, and Catholic content management.
- Prayer requests, Mass intentions, calendar, announcements, events, communities, ministries, reports, and finance workflows.
- Provider-independent Kanisa AI architecture and command center without AI provider integration.
- Event Intelligence and Automation Engine foundations without replacing existing workflows.

## Major Features

- Member portal.
- Pastoral workspace.
- Church Admin workspace.
- Finance workspace.
- Super Admin workspace.
- Personal Parish Assistant.
- Kanisa Command Center.
- Finance Intelligence.
- Catholic content tools.
- Contribution and pledge workflows.
- Role and invitation management.

## Architecture

- Workspace Framework is the single shell for primary authenticated workspaces.
- Shared page context supports workspace-aware pages without duplicating business logic.
- Query hooks and existing workflows are reused.
- Kanisa AI is provider-independent and does not call an AI provider in this release.
- Automation and Event Intelligence are local architecture foundations.

## Breaking Changes

- Legacy role-specific layouts were removed from primary workspace route trees.
- Primary workspace navigation is owned by `workspaceRegistry`.
- Dashboard rendering now avoids nested workspace shells.

## Known Limitations

- Community Leader routes still use a legacy layout and should be migrated or formally registered as a workspace.
- Large vendor chunks remain for PDF, chart, XLSX, scanner, and export libraries.
- Final production Supabase, storage, and email verification must be performed in the live environment.
- AI provider integrations are future work.
- Mobile app and website builder are future work.
