# Support Guide

## Common User Issues

- User cannot log in.
- Invitation link expired or was already used.
- User sees the wrong workspace.
- User cannot find Bible search results.
- Daily readings are missing.
- Prayer request or Mass intention status is unclear.
- Finance user cannot see expected reports.

## Troubleshooting

1. Confirm the user's email or phone number.
2. Confirm the church and member record.
3. Confirm the assigned role.
4. Confirm the workspace route.
5. Ask for the page URL and screenshot.
6. Check whether the issue is one user, one church, or platform-wide.

## Password Reset

- Ask the user to use Forgot Password.
- Confirm reset email delivery.
- Check spam or junk folders.
- If reset mail does not arrive, verify email provider configuration.

## Invitations

- Confirm the invitation was sent to the correct address.
- Resend if needed.
- Confirm the invited user is linked to the correct church.
- If the user already has an account, ask them to sign in before accepting where applicable.

## Permissions

- Confirm the user role in church role management.
- Confirm the user belongs to the correct church.
- Ask the user to refresh after role changes.
- If the workspace still appears wrong, ask the user to sign out and sign back in.

## Bible Search

Supported examples:

- `Matthew 3:16`
- `Matthew 3 : 16`
- `Matthew 3:16-17`
- `Mathayo 3:16`
- `Mt 3:16`

Whitespace and casing should not block search.

## Daily Readings

- Confirm the date.
- Confirm Catholic content import status.
- Confirm the readings are published for that date.
- If missing, route the issue to the Catholic content operator.

## Prayer Requests

- Confirm the member account is linked.
- Confirm the request status.
- Pastoral users should review pending items in the Pastoral workspace.

## Mass Intentions

- Confirm the member account is linked.
- Confirm the request status and desired date.
- Pastoral or church admin users should schedule or complete the intention as appropriate.

## Finance

- Confirm the user has Finance or authorized Church Admin access.
- Confirm the contribution, pledge, or report date range.
- Confirm whether payment references or receipts are expected.
- Do not expose private financial records to unauthorized users.
