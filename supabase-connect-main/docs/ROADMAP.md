# Product Roadmap

## Version 1.0

Pilot Edition:

- Unified Workspace Framework.
- Member, Pastoral, Church Admin, Finance, and Super Admin workspaces.
- Catholic content, Bible, daily readings, saints, announcements, calendar, prayer requests, Mass intentions, contributions, pledges, reports, and role management.
- Kanisa AI architecture without provider integration.
- Personal Parish Assistant, Event Intelligence, and Automation Engine foundations.

## Version 1.0.1

Critical fixes:

- Pilot defects that block daily parish workflows.
- Permission or routing defects discovered in production.
- High-priority mobile or accessibility fixes.
- Live environment issues from Supabase, storage, email, or deployment verification.

## Version 1.1

Pilot improvements:

- Usability improvements from parish feedback.
- Better empty states and copy on lower-traffic pages.
- Expanded browser smoke coverage.
- Community Leader workspace decision.

## Version 1.2

Stewardship:

- Finance reporting polish.
- Pledge and contribution workflow refinements.
- Receipt, reconciliation, and export improvements.
- Stewardship analytics improvements already discussed in Finance Intelligence.

## Version 1.3

Catholic Platform completion:

- Catholic content CMS improvements.
- Daily readings and liturgical calendar operations polish.
- Saints and prayer library editorial workflows.
- Import quality and validation follow-through.

## Version 2.0

Diocese Platform:

- Multi-parish oversight workflows.
- Diocese-level reporting and governance.
- Tenant readiness and onboarding operations.
