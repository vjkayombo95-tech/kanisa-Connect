# k6 load-test suite

These scripts are templates only; nothing here runs from `npm test` or deployment builds.
Set `BASE_URL`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and (where required) `TEST_ACCESS_TOKEN` in your terminal immediately before a manual k6 run. Use staging values only.

Run examples are in `docs/LOAD_TESTING.md`.
