# Saint Images

This folder prepares the future bulk image workflow.

Planned convention:

- Image filename should match the saint slug.
- Example: `st-peter.jpg` maps to `slug = st-peter`.
- Supported future extensions may include `.jpg`, `.jpeg`, `.png`, and `.webp`.

Automatic image upload and matching is not implemented yet. For now, upload images through the Saints CMS or include an external `image_url` in a published JSON file.
